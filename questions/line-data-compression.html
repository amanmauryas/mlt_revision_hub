Compressing points that lie on a line

How much storage do we save when 100 points in three dimensions all lie on a single line through the origin?

PCA intuitionDimensionality reductionStorage calculation

Question

Consider a dataset that has 100 points that belong to \(\mathbb{R}^3\). All of them are found to lie on a line that passes through the origin. We use a unit vector along the line as a representative and the coefficients with respect to it to represent the individual data-points. Compute the percentage decrease in the size of the dataset if we move to this new representation. Assume that it takes one unit of space to store one feature. Enter your answer correct to two decimal places; it should be in the range \([0,100]\).

Hint 1: how many numbers are needed to store 100 points in \(\mathbb{R}^3\)?

Hint 2: the direction vector is stored once, and each point needs one scalar coefficient.

See the representation change

Every point lies on the same line through the origin. Instead of storing three coordinates per point, store the shared direction once and one coefficient per point.

Key idea: the 100 points do not each need a separate 3D direction. One shared unit vector describes the line; each point is identified by a single scalar along it.

Step-by-step solution

  1. Original representation: each of the 100 points has 3 features, so storage is \(100\times3=300\) units.
  2. New representation: store the shared unit vector once (3 numbers) and one scalar coefficient for each point (100 numbers). Total \(3+100=103\) units.
  3. Space saved: \(300-103=197\) units.
  4. Percentage decrease: \(\frac{300-103}{300}\times100=\frac{197}{300}\times100=65.666\ldots\%\).
\[\boxed{65.67\%}\]

Why not 66.67%?

It is tempting to say each point goes from 3 numbers to 1, so storage drops by two-thirds. That ignores the cost of storing the shared direction vector. Since the problem asks for the size of the whole dataset representation, include the 3 numbers used to store the unit vector:

\[\text{new size}=100(1)+3=103,\quad\text{not }100.\]

If the direction vector were already stored elsewhere and explicitly excluded from the storage budget, the answer would instead be 66.67%. Under the stated representation, count it once.

Exam takeaway

  • Original storage: number of points × ambient dimension.
  • Reduced storage: shared basis/direction storage + number of coefficients.
  • Percentage decrease: \(\frac{\text{old}-\text{new}}{\text{old}}\times100\%\).
  • Always check whether the shared representation itself must be counted.
