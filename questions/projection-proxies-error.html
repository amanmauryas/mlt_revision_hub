Question 5 · Identify the error vector

Which vector represents the reconstruction error when Q is used as the proxy for P?

Choose an answer.

Show solution

The error vector is the difference between the original point and its proxy: e = P − Q. Geometrically, it points from Q to P, so it is QP.

Question 6 · Is Q the best proxy?

Which point on the line gives the best representation of P?

Choose an answer.

Show solution

The best proxy minimizes reconstruction error. This occurs at the orthogonal projection Q′, where residual P − Q′ is perpendicular to the line. Use “Set Q to Q′” to see the minimizing point.

Question 7 · Compare reconstruction errors

For a non-optimal proxy Q, which statements are guaranteed when Q′ is the best proxy? Select the two true statements.

Select the true statements (multiple selections supported).

Show solution

The orthogonal projection minimizes distance to P, so ‖Q′P‖ ≤ ‖QP‖, with strict inequality if Q ≠ Q′. Distinct points Q and Q′ on the line have positive distance, so ‖QQ′‖ > 0. In the supplied assignment, the correct choices are (b) and (d).

Core derivation

Let u be a unit direction vector along the line. Every point on the line has the form Q = tu. To find the best coefficient, minimize squared error:

\[f(t)=\|P-tu\|^2=(P-tu)^T(P-tu).\]

Differentiate with respect to t and set the result to zero:

\[f'(t)=-2u^TP+2t(u^Tu)=0.\]

Because u is a unit vector, uᵀu = 1, hence

\[t^*=u^TP,\qquad Q'=(u^TP)u.\]

The residual is perpendicular to the line because \(u^T(P-Q')=0\). This is the projection formula used in PCA.

Exam takeaways

  • Error vector: original minus proxy, \(e=P-Q\).
  • Best proxy on a line: orthogonal projection onto that line.
  • At the optimum, residual and line direction are perpendicular.
  • Minimizing squared error and minimizing error length give the same proxy because squaring preserves order for nonnegative lengths.
