Finding a unit-length representative

Topic: PCA · Principal directions and dimensionality reduction

Question

Consider the dataset of four points, all of which lie on a line:

\[ S=\left\{ \begin{bmatrix}0\\0\end{bmatrix}, \begin{bmatrix}3\\4\end{bmatrix}, \begin{bmatrix}6\\8\end{bmatrix}, \begin{bmatrix}1/5\\4/15\end{bmatrix} \right\}. \]

Among the following vectors, choose a representative that has unit length.

  1. \(\begin{bmatrix}3\\4\end{bmatrix}\)
  2. \(\begin{bmatrix}1/15\\4/15\end{bmatrix}\)
  3. \(\begin{bmatrix}3/5\\4/5\end{bmatrix}\)
  4. \(\begin{bmatrix}1\\1\end{bmatrix}\)
Hint

Normalize the direction vector by dividing it by its Euclidean length. A unit vector must have norm 1.

Solution

Correct answer: C, \(w=\begin{bmatrix}3/5\\4/5\end{bmatrix}\).

The point \(\begin{bmatrix}3\\4\end{bmatrix}\) indicates the direction of the line, but it is not unit length:

\[ \left\|\begin{bmatrix}3\\4\end{bmatrix}\right\| =\sqrt{3^2+4^2}=5. \]

Divide by 5 to obtain the unit representative:

\[ w=\frac{1}{5}\begin{bmatrix}3\\4\end{bmatrix} =\begin{bmatrix}3/5\\4/5\end{bmatrix}, \qquad \|w\|=1. \]

How does the last point get represented?

Every point on this line can be written as \(x=cw\), where \(c\) is a scalar coefficient. For the last point, solve

\[ \begin{bmatrix}1/5\\4/15\end{bmatrix} =c\begin{bmatrix}3/5\\4/5\end{bmatrix}. \]

Comparing first coordinates gives \(c(3/5)=1/5\), so \(c=1/3\). Checking the second coordinate confirms it:

\[ \frac13\cdot\frac45=\frac4{15}. \]

Thus the last point is not a new representative vector. It is one-third of the same unit vector:

\[ \boxed{\begin{bmatrix}1/5\\4/15\end{bmatrix}=\frac13w}. \]

Coefficients for all four points

Point \(x\)Coefficient \(c\) in \(x=cw\)
\(\begin{bmatrix}0\\0\end{bmatrix}\)\(0\)
\(\begin{bmatrix}3\\4\end{bmatrix}\)\(5\)
\(\begin{bmatrix}6\\8\end{bmatrix}\)\(10\)
\(\begin{bmatrix}1/5\\4/15\end{bmatrix}\)\(1/3\)

Try it yourself

With the same unit representative \(w=\begin{bmatrix}3/5\\4/5\end{bmatrix}\), what coefficient represents \(x=\begin{bmatrix}6\\8\end{bmatrix}\)?

Exam traps

  • \([3,4]^T\) gives the correct direction but has length 5, not 1.
  • The representative vector is shared across all points; each point gets its own coefficient.
  • Because \(w\) is unit length, the coefficient is the signed distance along the line from the origin.
