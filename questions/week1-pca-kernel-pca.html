Week 1 — PCA: summary pointers

What PCA optimizes

Find orthogonal directions that maximize projected variance. The first component captures the most variance; each later component captures the most remaining variance subject to orthogonality.

Covariance and eigenpairs

C = (1/n) XᵀX (centered rows-as-points X)
For a covariance eigenpair Cw = λw with unit w, variance along w is wᵀCw = λ. Sort eigenvalues descending.

Projection & reconstruction

z = Wₖᵀ(x − μ)
x̂ = μ + Wₖz
For centered data and orthonormal components, the residual is orthogonal to the retained subspace.

Explained variance

EVR(k) = (λ₁ + … + λₖ) / (λ₁ + … + λd)
Total variance equals the sum of covariance eigenvalues (the trace of C).

Rank & exact reconstruction

Number of nonzero covariance eigenvalues is at most min(d, n−1) for n centered samples in d dimensions. If data lie in an r-dimensional subspace, r suitable components suffice for zero reconstruction error.

Common traps

Eigenvector sign is arbitrary. Components are directions, not the projected coordinates. PCA is unsupervised and does not necessarily preserve class separation. Center before standard PCA; scaling features may matter.

Week 2 — Kernel PCA: short notes

Kernel idea

A kernel computes inner products in a feature space without explicitly constructing φ(x): k(x,z)=φ(x)ᵀφ(z). This can make nonlinear structure linearly accessible in feature space.

Kernel matrix

Kᵢⱼ = k(xᵢ,xⱼ)
Kc = HKH, H = I − (1/n)11ᵀ
Center the Gram matrix in feature space before Kernel PCA.

Eigenvalue scaling

For centered feature matrix Φ, Kc = ΦΦᵀ. Nonzero eigenvalues of ΦΦᵀ and ΦᵀΦ agree. If covariance uses 1/n, its eigenvalues are kernel-matrix eigenvalues divided by n.

Common kernels

Polynomial: (xᵀz + c)ᵖ
RBF: exp(−γ‖x−z‖²)
Higher polynomial degree increases flexibility but can also overfit or create numerical issues.

Valid kernel checks

A valid kernel produces a symmetric positive semidefinite Gram matrix for every finite dataset. Nonnegative sums and products of valid kernels remain valid under standard conditions.

Kernel PCA vs PCA

Standard PCA captures linear directions in input space; Kernel PCA captures directions in an implicit feature space. It is not guaranteed to outperform PCA or always reduce dimension. Out-of-sample projection needs kernel evaluations against training points.
