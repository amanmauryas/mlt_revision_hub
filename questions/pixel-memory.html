How much memory does an image dataset occupy?

Estimate storage from image count, image dimensions, and bytes per pixel. This question tests unit conversion and careful multiplication.

Data representationArithmeticExam fundamentals

Question

A dataset contains 1,000 images. Each image has dimensions 100 × 100 pixels. Every pixel is stored using a 32-bit floating-point number (4 bytes). Ignoring metadata and compression, estimate the total storage in MB and MiB.

Hint: calculate pixels in one image first, multiply by bytes per pixel, then multiply by the number of images. Convert bytes only at the end.

1,000 × 100 × 100 × 4 = 40,000,000 bytes

Step-by-step solution

  1. Pixels per image: \(100\times100=10{,}000\).
  2. Bytes per image: \(10{,}000\times4=40{,}000\) bytes.
  3. Bytes for 1,000 images: \(1{,}000\times40{,}000=40{,}000{,}000\) bytes.
  4. Decimal megabytes: \(40{,}000{,}000/10^6=40\text{ MB}\).
  5. Binary mebibytes: \(40{,}000{,}000/2^{20}\approx38.15\text{ MiB}\).
\[\text{Memory} = N\times H\times W\times B\]

Here \(N\) is the number of images, \(H,W\) are image dimensions, and \(B\) is bytes per pixel.

Common mistakes / exam traps

  • Confusing bits with bytes: 32 bits = 4 bytes, not 32 bytes.
  • Using \(100+100\) instead of \(100\times100\) pixels.
  • Mixing MB (1,000,000 bytes) and MiB (1,048,576 bytes).
  • For RGB values, clarify whether the stated bytes are per channel or per pixel. If it is 4 bytes per channel across 3 channels, use 12 bytes per pixel.
  • The estimate excludes labels, metadata, padding, temporary copies, and model-side memory.
